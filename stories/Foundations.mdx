# Foundations

Frame UI는 React 19와 StyleX로 만드는 UI kit입니다. 현재 색상·타입·간격은 검증 fixture 전용 값이며 공개 디자인 토큰이 아닙니다. 토큰·테마는 이슈 #4에서 정의합니다.

이 Storybook은 문서, 상태 예제, 실제 Chromium 동작·접근성·시각 검증의 기준입니다. fixture에는 로컬 Noto Sans KR 400/600을 사용하고 외부 폰트 요청을 하지 않습니다.
