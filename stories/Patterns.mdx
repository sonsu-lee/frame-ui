# 동작·접근성 검증

`pnpm test:storybook`은 일회성 Vitest 실행으로 Story의 `play` assertion과 addon-a11y를 검사합니다. 검사는 Playwright Chromium browser mode에서 실행됩니다.

접근성 검사 대상은 manager UI가 아닌 preview body이며 Portal도 포함합니다. WCAG 2.2 A/AA 태그를 사용하고 fragment의 랜드마크 소유권 때문에 `region` 규칙만 해제합니다. 이 예외는 소비 앱 전체 문서의 접근성 검사를 대신하지 않습니다.

axe 위반은 실패하고 `incomplete` 결과는 수동 확인 대상입니다. 자동 검사 통과가 접근성 전체를 보장하지 않으므로 키보드 순서·focus 표시와 복귀, 좁은 화면·긴 문구·실제 브라우저 확대를 관련 UI에서 확인하고 기록합니다.
